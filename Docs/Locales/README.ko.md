# Cinder

[English](../../README.md) · **한국어** · [日本語](README.ja.md)

**오디오 번인을 간편하게.**

Cinder는 이어폰과 헤드폰을 위한 Mac용 오디오 번인 앱입니다.
핑크 노이즈, 주파수 스윕, 직접 고른 음악 파일이나 내장 음악 7곡을 재생하세요.
재생 시간과 휴식 간격을 정하고, 메뉴 막대에서 재생을 제어하며,
지난 실행 기록을 확인할 수 있습니다.

현재 버전은 **1.0.0-dev**이며 **macOS 14 Sonoma 이상 · Apple Silicon**을 대상으로 합니다.
첫 정식 출시를 준비하는 개발판입니다. [변경 기록(영문)](../../RELEASE-NOTES.md)에서 기능과 개선 사항을 확인할 수 있습니다.
macOS 14·15·26에서의 호환성 검증은 진행 중입니다.
[현재 제한 사항과 검증 범위(영문)](../../VALIDATION.md)를 확인하세요.

## 처음 시작하기

1. 로컬 빌드한 `Cinder (Dev).app`을 엽니다. 빌드 방법은 아래의 **로컬 빌드**를 참조하세요.
2. 빠른 시작에서 연결한 이어폰·헤드폰의 출력 장치를 선택합니다.
3. 재생 신호와 실행 계획을 고릅니다. 전체 사이클은 60분 이상이며, 분할 실행은 회당 시간과 휴식 간격을 직접 정합니다.
4. 음악을 사용할 경우 음악 탭에서 내장 음악을 고르거나 Mac의 음악 파일을 추가합니다.
5. 이어폰을 착용하지 않은 상태에서 시스템·DAC 볼륨을 낮게 설정하고, 출력 장치와 앱 게인을 확인한 뒤 시작합니다.

재생 중에는 메인 창이나 메뉴 막대에서 일시정지·재개·중지할 수 있습니다.
내장 신호와 음악 재생에는 계정이나 인터넷 연결이 필요하지 않습니다.

## 주요 기능

- **빠른 시작:** 노이즈·음악·주파수 스윕 또는 60분 전체 사이클을 선택합니다. 한 화면에서 시작·일시정지·재개·중지를 제어합니다.
- **빠른 시작 간편 모드:** 메뉴 막대에서 출력 장치와 재생 시간을 선택하고 재생을 제어합니다. 상태·남은 시간·예약 시각도 확인할 수 있습니다.
- **음악:** 음악 파일을 선택하고 순서를 바꾸며 파일 정보와 초기 읽기 결과를 확인합니다. 내장 음악 7곡 중 한 곡을 반복 재생할 수도 있습니다.
- **출력:** 선택한 장치의 연결 방식·제조사·현재 샘플레이트·출력 채널 수·지원 샘플레이트를 확인합니다. 게인 조절과 프리셋 저장, Peak/RMS 미터를 제공합니다. Mac 정보와 공개 참고 사양은 별도로 표시합니다.
- **예약:** 일회성·반복 예약을 설정합니다. 재생·예약 프리셋을 JSON/YAML 파일로 가져오거나 내보낼 수 있습니다.
- **설정:** 한국어·영어·일본어, 시스템·라이트·다크·사용자 테마, 막대형·바늘형 미터, Dev·Stable 업데이트 채널을 선택합니다.
- **실행 기록(설정):** 최근 500개 실행의 시간·휴식·게인·완료/중단 결과를 확인합니다. 기록 검색, 요약 복사와 내보내기를 지원합니다.

초기 앱 게인은 −30 dB, 수동 조절 범위는 −60~0 dB입니다. 장치나 참고 프로파일을
선택해도 게인은 자동으로 바뀌지 않습니다. 디지털 게인과 미터는 실제 음압을
나타내지 않습니다. 앱을 열거나 프리셋을 불러오는 것만으로 재생·예약을 시작하지 않습니다.

## 실행 계획

| 선택 | 동작 |
|---|---|
| 40시간 연속 | 40시간을 한 세션으로 실행 |
| 40시간 분할 | 회당 시간과 회차 사이 휴식을 직접 지정. 마지막 회차를 남은 시간으로 조정해 세션 합계 40시간 실행 |
| 직접 시간 설정 | 1분부터 1000시간까지 분 단위로 한 세션 실행 |

예를 들어 회당 3시간, 휴식 30분이면 3시간 13회와 마지막 1시간으로 나뉩니다.
회차 사이 휴식 13회를 포함한 예상 소요 시간은 46시간 30분입니다.
휴식이 끝나면 다음 회차를 자동으로 시작합니다. 창을 닫아도 계속 실행되며,
중지·앱 종료·출력 장치 변경이나 연결 해제 시 남은 계획을 취소합니다.
잠자기 등으로 다음 시작을 1분 넘게 놓치면 자동 재개하지 않습니다.

40시간은 선택 가능한 계획이며 모든 기기에 권장되는 번인 시간이 아닙니다.
세션 시간에는 선택한 전체 사이클 안의 휴식이 포함되고, 회차 사이 휴식은 별도로 더해집니다.
빠른 시작은 세션 시간·신호 구간·사이클 휴식·회차 사이 휴식을 따로 표시합니다.
완료 예상 시각은 분할 계획 전체를 기준으로 하며 일시정지·준비 시간에 따라 늦어집니다.
전체 사이클을 선택할 때는 마지막 회차를 포함해 매회 60분 이상이어야 합니다.

빠른 시작 간편 모드에서는 1·2·4·8시간이나 직접 입력한 시간으로 한 번 재생하거나,
40시간 연속 계획을 선택할 수 있습니다. 기존 40시간 분할 계획도 선택할 수 있습니다.
회당 시간·휴식 간격·재생 신호·음악·게인은 메인 창에서 조절하며, 간편 모드에도 같은
설정을 적용합니다. 팝업을 열기만 해서는 계획이 바뀌지 않습니다.
실행 중이나 예약 대기 중에는 장치와 재생 시간을 변경할 수 없습니다.

창의 닫기 버튼이나 ⌘W는 창만 닫습니다. **Cinder 종료 또는 ⌘Q**는 재생을
끝내고 남은 예약과 실행 계획을 취소합니다. 메뉴 막대의 **Cinder 열기**로
진행 중인 세션에 돌아갈 수 있습니다. 종료 후 재실행 시 재생이나 예약을 자동 복원하지 않습니다.
메뉴 막대 아이콘의 위치를 바꾸려면 ⌘를 누른 채 Cinder 아이콘을 드래그하세요.
[Apple의 메뉴 막대 안내](https://support.apple.com/guide/mac-help/whats-in-the-menu-bar-mchlp1446/mac)를 참조하세요.

## 실행 기록과 현재 제한 사항

실행 기록은 이 Mac에 저장됩니다. 비정상 종료 후에는 마지막으로 저장한 기록을
복원하며 재생·예약을 자동으로 시작하지 않습니다. 가장 최근의 활동은 기록에서
누락될 수 있습니다. 총계는 보관된 최근 500개 실행을 기준으로 합니다.
음악 파일 경로나 장치 식별자는 기록·요약에 포함하지 않습니다.

현재는 개발판이며 실제 장치 재생, 내장 음악의 품질, 장시간 실행과 설치를
검증하고 있습니다. 확인된 항목과 남은 제한 사항은
[검증 범위(영문)](../../VALIDATION.md)를 참조하세요.

## 로컬 빌드

`dev` 브랜치의 소스로 개발판을 빌드합니다. 빌드에는 macOS 27 이상과 Xcode 27이
설치된 Apple Silicon Mac이 필요합니다. 이 빌드 환경 조건은 앱의 최소 실행 버전인
macOS 14와 별개입니다. 최초 준비 시 인터넷 연결이 필요합니다.

```bash
bash Setup-Mac.command
bash Check-Xcode.command
bash Build-App.command
```

생성된 `dist/Cinder (Dev).app`을 엽니다. 개발 빌드는 로컬 서명을 사용하며
Developer ID 서명·공증된 배포본은 아닙니다. 자세한 환경 조건과 패키징 방법은
[빌드 안내(영문)](../BUILDING.md)를 참조하세요.

## 화면과 알림

완료·오류 알림은 설정에서 켤 수 있습니다. 처음 켤 때 macOS 알림 허용을 요청합니다.
완료·장치 변경·실패·놓친 예약을 소리 없는 알림으로 알려줍니다.
일시정지나 회차 사이 휴식마다 알리지 않습니다. 허용하지 않아도 실행 기록은 남습니다.

주 화면은 빠른 시작·음악·출력·설정으로 구성됩니다. 출력 탭에서 장치·게인·Mac 정보를
확인하며, 빠른 시작의 출력 상세 버튼도 이 탭으로 이동합니다. 예약은 빠른 시작에서,
실행 기록은 설정에서, 변경 기록과 도움말은 설정의 Cinder 정보에서 열 수 있습니다.
긴 음악 목록과 변경 기록은 검색 또는 페이지 이동으로 확인합니다.

앱이 활성화된 동안 `⌘Return`으로 시작·일시정지·재개, `⌘.`으로 중지합니다.
`⌘1`–`⌘4`는 주 화면을 전환하며, `⌘,`는 설정을 엽니다. 예약 대기나 준비 중에는
시작 단축키도 비활성화됩니다. 다른 음악 앱의 전역 미디어 키를 가로채지 않습니다.

## 업데이트

정식판은 아직 출시되지 않았습니다. **설정 → 업데이트**에서 Dev·Stable 채널
선택을 저장하고 설치된 버전을 확인할 수 있습니다. 채널을 선택해도 앱이 교체되거나
재생이 바뀌지 않습니다. 자동 업데이트 다운로드와 설치는 아직 제공하지 않습니다.
