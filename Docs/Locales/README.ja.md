# Cinder

[English](../../README.md) · [한국어](README.ko.md) · **日本語**

**オーディオのバーンインを、もっと手軽に。**

Cinderは、イヤホンとヘッドホンのためのMac用オーディオバーンインアプリです。
ピンクノイズ、周波数スイープ、手持ちの音楽ファイル、内蔵音楽7曲から
再生する音を選び、時間と休憩間隔を設定します。メニューバーから再生を操作でき、
過去の実行履歴も確認できます。

現在のバージョンは **1.0.0-dev**、対象環境は **macOS 14 Sonoma以降 · Apple Silicon** です。
初の正式リリースに向けた開発版です。機能と変更内容は
[リリースノート（英語）](../../RELEASE-NOTES.md)をご覧ください。
macOS 14・15・26での互換性検証は進行中です。
[現在の制限事項と検証状況（英語）](../../VALIDATION.md)をご覧ください。

任意提供の **Intel（x86_64）試験版の対応範囲はmacOS 14〜26のみ**です。
**Intel向けのmacOS 27以降には対応しません**。
試験版は[GitHubのプレリリース](https://github.com/alienatiz/Cinder/releases)で配布します。
[Intel版のインストールと検証範囲（英語）](../INSTALLING-INTEL.md)をご確認ください。
実際のIntel Macでの検証はまだ完了していません。

## はじめに

1. ローカルでビルドした `Cinder (Dev).app` を開きます。手順は下の **ローカルビルド** を参照してください。
2. クイック再生で、イヤホンやヘッドホンを接続した出力デバイスを選びます。
3. 信号と実行プランを選びます。フルサイクルには60分以上が必要です。分割実行では、1回の時間と休憩間隔を指定します。
4. 音楽を使う場合は、「音楽」タブで内蔵曲を選ぶか、Macの音楽ファイルを追加します。
5. イヤホンを耳から外し、システムやDACの音量を低く設定します。出力先とアプリのゲインを確認してから開始してください。

再生中はメインウインドウやメニューバーから一時停止・再開・停止できます。
内蔵信号と音楽の再生に、アカウントやインターネット接続は必要ありません。

## 主な機能

- **クイック再生:** ノイズ・音楽・周波数スイープ、または60分のフルサイクルを選べます。開始・一時停止・再開・停止を一画面で操作できます。
- **クイック再生 簡易モード:** メニューバーで出力先と再生時間を選び、再生を操作できます。状態・残り時間・開始予定も確認できます。
- **音楽:** 音楽ファイルの選択と並べ替え、ファイル情報と初期読み取り結果の確認ができます。7曲の内蔵音楽から1曲を選んで繰り返し再生することもできます。
- **出力:** 選択したデバイスの接続方式・メーカー・現在のサンプルレート・出力チャンネル数・対応サンプルレートを確認できます。ゲインの調整とプリセット保存、Peak/RMSメーターを利用できます。Mac情報と公開参考仕様は別に表示します。
- **予約:** 1回限り・繰り返しの予約を設定できます。再生・予約プリセットをJSON/YAMLファイルで読み込み・書き出しできます。
- **設定:** 英語・韓国語・日本語、システム・ライト・ダーク・カスタムテーマ、バー型・針型のメーター、Dev・Stable更新チャンネルを選べます。
- **実行履歴（設定）:** 直近500件の実行時間・休憩・ゲイン・完了や中断の結果を確認できます。記録の検索、要約のコピーと書き出しに対応します。

アプリの初期ゲインは−30 dB、手動調整の範囲は−60〜0 dBです。
デバイスや参考プロファイルを選んでもゲインは自動で変わりません。
デジタルゲインとメーターは実際の音圧を示しません。アプリを開いたり
プリセットを読み込んだりするだけでは、再生や予約は開始されません。

## 実行プラン

| 選択 | 動作 |
|---|---|
| 40時間の連続実行 | 40時間を1回のセッションとして実行 |
| 40時間の分割実行 | 1回の時間と休憩間隔を指定。最後のセッションを残り時間に調整し、セッションの合計を40時間にする |
| 時間の直接指定 | 1分から1000時間まで、1分単位で1回のセッションを設定 |

たとえば1回3時間、休憩30分の場合、3時間のセッション13回と最後の1時間に
分かれます。13回の休憩を含む予定所要時間は46時間30分です。休憩が終わると
次のセッションが始まります。ウインドウを閉じても継続し、停止・アプリの終了・
出力先の変更や切断で残りのプランを取り消します。スリープなどで次の開始時刻を
1分以上過ぎた場合、自動では再開しません。

40時間は選択できるプランであり、すべての機器に推奨するバーンイン時間では
ありません。セッション時間にはフルサイクル内の休憩を含み、セッション間の
休憩は別途加算します。クイック再生ではセッション・信号・サイクル内の休憩・
セッション間の休憩を分けて表示します。完了予定は分割プラン全体が対象で、
準備や一時停止により遅くなります。フルサイクルを選んだ場合、最後を含む
各セッションに60分以上が必要です。

クイック再生 簡易モードでは、1・2・4・8時間または直接入力した時間で1回の
セッションを実行するか、40時間の連続プランを選べます。既存の40時間分割プランも
選べます。1回の時間・休憩・信号・音楽・ゲインはメインウインドウで設定し、
簡易モードでも同じ設定を使います。ポップアップを開くだけではプランは変わりません。
実行中や予約待機中はデバイスと再生時間を変更できません。

閉じるボタンや⌘Wで閉じるのはウインドウだけです。**Cinderを終了、または⌘Q**
で再生を終了し、残りの予約とプランを取り消します。メニューバーの
**Cinderを開く** からセッションに戻れます。アプリを再起動しても再生や予約を
自動では復元しません。メニューバーアイコンの位置を変えるには、⌘を押しながら
Cinderのアイコンをドラッグしてください。[Appleのメニューバーガイド](https://support.apple.com/guide/mac-help/whats-in-the-menu-bar-mchlp1446/mac)も参照できます。

## 実行履歴と現在の制限事項

実行履歴はこのMacに保存されます。予期しない終了後は最後に保存した記録を
復元し、再生や予約を自動では開始しません。直前の活動が記録に残らない場合が
あります。集計対象は保持している直近500件です。音楽ファイルのパスや
デバイス識別子は記録や要約に含めません。

現在は開発版であり、実機での再生、内蔵音楽の品質、長時間の実行、
インストールを検証しています。確認済みの項目と残る制限事項は
[検証状況（英語）](../../VALIDATION.md)をご覧ください。

## ローカルビルド

`dev`ブランチのソースから開発版をビルドします。ビルドにはmacOS 27以降と
Xcode 27を備えたApple Silicon Macが必要です。このビルド環境の要件は、
アプリの最小実行バージョンであるmacOS 14とは別です。初回の準備には
インターネット接続が必要です。

```bash
bash Setup-Mac.command
bash Check-Xcode.command
bash Build-App.command
```

生成された `dist/Cinder (Dev).app` を開きます。開発ビルドはローカル署名を使用し、
Developer ID署名・公証済みの配布版ではありません。詳しい環境要件とパッケージ作成は
[ビルドガイド（英語）](../BUILDING.md)を参照してください。

## 画面と通知

完了・エラー通知は設定で任意に有効にできます。初めて有効にするときに
macOSの通知許可を求めます。完了・デバイス変更・失敗・実行できなかった予約を
音なしで通知し、一時停止や休憩のたびには通知しません。許可しなくても記録は残ります。

主な画面はクイック再生・音楽・出力・設定です。出力タブでデバイス・ゲイン・Mac情報を
確認できます。クイック再生の出力詳細ボタンもこのタブを開きます。予約はクイック再生、
実行履歴は設定、変更履歴とヘルプは設定のCinderについてから開けます。
長い音楽リストや変更履歴は検索またはページ切り替えで確認できます。

アプリの操作中は `⌘Return` で開始・一時停止・再開、`⌘.` で停止できます。
`⌘1`〜`⌘4` で画面を切り替え、`⌘,` で設定を開きます。予約待機中や準備中は
開始のショートカットも無効です。他のプレイヤーのグローバルなメディアキーを
横取りしません。

## 更新

正式版はまだリリースされていません。**設定 → 更新** ではDev・Stableチャンネルの
選択を保存し、インストール済みのバージョンを確認できます。選択だけではアプリや
再生は変わりません。自動更新のダウンロードとインストールは未対応です。
